# Raulif Travel

Plataforma de turismo/aventura (cliente real).

## Stack
- Frontend HTML/CSS + backend
- Docker + VPS
- GitHub Actions

## Estructura
```
index.html      Landing
backend/        API
assets/         Recursos
docs/           Documentación (incluye prototipo UI)
dist/           Build
docker-compose.yml
```

## Diseño
Estilo "cuaderno de viaje" con fondo topográfico crema, acentos esmeralda+ámbar.
Referencia: `docs/prototipo-ui-aventura.html`.
