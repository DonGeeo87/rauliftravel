Documento vivo para el proyecto de web app de **rutas de turismo aventura y turismo consciente** (marketplace multi-proveedor, ganancias por comisión).

| Archivo | Contenido |

## Cómo usar
1. Abre `flujo-web.html` en el navegador para el diagrama visual.
2. Lee `01-brief-requisitos.md` y responde las **preguntas abiertas Q1–Q4** (definen el 80% del diseño).
3. Sigue el `02-roadmap.md` para ejecutar.

> **Pendiente principal:** responder las 4 preguntas del brief antes de construir el MVP.
